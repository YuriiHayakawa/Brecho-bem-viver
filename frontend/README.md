# Frontend - Bazar Sebrae

Este diretório contém o frontend da aplicação, criado com **React** e **Vite**.

## Pré-requisitos

- Node.js (versão LTS recomendada)
- npm (gerenciador de pacotes padrão do Node)

Verifique se o Node está instalado:

```bash
node -v
npm -v
```

## Instalação das dependências

Dentro da pasta `frontend`:

```bash
cd frontend
npm install
```

## Executar o servidor de desenvolvimento

Ainda dentro da pasta `frontend`:

```bash
npm run dev
```

Por padrão, o Vite vai subir o servidor em `http://localhost:5173`.

## Estrutura básica

- `index.html` — Arquivo HTML principal carregado pelo Vite.
- `src/main.jsx` — Ponto de entrada da aplicação React.
- `src/App.jsx` — Componente principal de exemplo.
- `src/styles.css` — Estilos globais iniciais.

A partir desta base, você pode criar novas páginas, componentes e rotas conforme a necessidade do projeto.
